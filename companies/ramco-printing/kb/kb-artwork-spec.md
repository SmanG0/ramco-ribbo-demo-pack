# Artwork Requirements

> `[VERIFY]` **Every specification in this file must be confirmed against Ramco Printing's prepress requirements before go-live.** The values below are print-industry conventions, not Ramco Printing's published standards, and prepress requirements vary by press, product and division.
> Do not state any figure from this document to a customer until prepress has confirmed it.

## Why this file is cautious

Artwork specification is where a bot can do real damage cheaply. If it tells a customer 3mm bleed and Ramco Printing's prepress wants 5mm on packaging, the file gets rejected, the job stalls, and the delay is our fault.

The industry conventions below are almost certainly close. "Almost certainly close" is not good enough to state as Ramco Printing's requirement.

## Delivery of artwork

**The bot does not accept artwork.** WhatsApp compresses images, strips colour profiles and does not preserve vector data. A file arriving this way is not printable and accepting it creates a false impression that the job can proceed.

Direct customers to the proper route — email to the division or an upload link.

`[VERIFY]` Obtain the correct artwork submission route per division, and the file size limit.

## What the bot can usefully do

Even without confirmed figures, it can:

- Explain **that** artwork requirements exist and that prepress will check the file
- Explain **why** a rejected file delays a job, so the customer takes it seriously
- Route the file to the right place
- Capture whether the customer **has** print-ready artwork, needs design work, or is supplying something that will need reworking — which is exactly what an estimator needs to know upfront

That last point is valuable on its own. "Do you have print-ready artwork, or would you like us to set it up?" is a question that changes the quote, and asking it early prevents a nasty surprise later.

## Common causes of rejection

Worth explaining generally, since it helps customers avoid delay:

- Supplied in RGB instead of CMYK, so colours shift
- Images too low resolution once scaled to final size
- No bleed, so trimming leaves white edges
- Fonts neither outlined nor embedded, so they substitute
- Text too close to the trim edge
- Packaging supplied without a die-line

The bot may describe these as common problems to watch for. It may **not** state Ramco Printing's specific tolerances until verified.
